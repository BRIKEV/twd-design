# Brand

TWD Design is part of the [TWD](https://twd.dev) ecosystem and uses its brand.

| | |
|---|---|
| Name | **TWD Design** (repo, image and bot handle: `twd-design`) |
| Tagline | **Test While Designing.** |
| Deep teal | `#123956`: primary on light backgrounds, Slack app color |
| Teal | `#2faaae`: primary on dark backgrounds, accents |
| Teal (surface) | `#1a7c80`: backgrounds behind white text |

## Files

| File | Use |
|---|---|
| `slack-icon.png` | Slack app icon (512×512). Upload it in your Slack app → **Basic Information → Display Information → App icon**. |
| `twd-logo.png` | TWD logo with wordmark, for docs and READMEs. |

Prototypes don't carry TWD's brand: they use **your** design guide. They only show a small
"Prototype · tests by TWD" mark in the screen switcher, which is prototype scaffolding.

Teams that run their own instance can rename the bot and use their own icon: see
[Create the Slack app](../site/docs/setup/slack-app.md).
